Performance Benchmark

Median of several timed runs per stage. Render stages go from TraceData straight into a fresh <trace-visualizer> and include layout and paint (double rAF). The full scenario matrix, with frame times and long tasks, is perf.html.

Performance Targets

  • Transform (flat logs → OTel): ≤ 5 ms @ 100, ≤ 50 ms @ 1 K, ≤ 250 ms @ 10 K
  • Index (buildSpanIndex: links, order, typed-array table): ≤ 2 ms @ 100, ≤ 20 ms @ 1 K, ≤ 100 ms @ 10 K, ≤ 400 ms @ 50 K
  • Mount (JS) (create the element, hand it TraceData, flush the store): no target
  • First frame (mount + layout + paint): ≤ 100 ms @ 5 K, ≤ 400 ms @ 50 K spans
  • Zoom / Pan / Collapse all (input → painted frame, two rAF): ≤ 50 ms at every scale
  • Total pipeline (transform + index + first frame): ≤ 150 ms @ 1 K, ≤ 1 000 ms @ 50 K

Choose the painter with #renderer=canvas or #renderer=dom (default: the element's auto).
