Performance Benchmark

Median of multiple timed runs per stage, after JIT warmup. Results include browser paint via double-rAF.

Performance Targets

  • Transform (logs → OTel): ≤ 5 ms @ 100, ≤ 50 ms @ 1 K, ≤ 250 ms @ 10 K
  • Tree build (index + sort): ≤ 2 ms @ 100, ≤ 20 ms @ 1 K, ≤ 100 ms @ 10 K
  • HTML generate (template strings): ≤ 5 ms @ 100, ≤ 50 ms @ 1 K, ≤ 500 ms @ 10 K
  • DOM render (JS) (innerHTML + event listeners): ≤ 50 ms @ 100, ≤ 200 ms @ 1 K, ≤ 2 000 ms @ 10 K
  • DOM render (+ paint) (JS + layout + paint via double-rAF): no target
  • Zoom (wheel zoom + repaint): ≤ 50 ms @ 100, ≤ 100 ms @ 1 K, ≤ 500 ms @ 10 K (RAIL animation + INP “good”)
  • Pan (drag pan + repaint): ≤ 50 ms @ 100, ≤ 50 ms @ 1 K, ≤ 200 ms @ 10 K (RAIL animation + INP “good”)
  • Total pipeline (logs in → pixels on screen): ≤ 50 ms @ 100, ≤ 300 ms @ 1 K, ≤ 3 000 ms @ 10 K
