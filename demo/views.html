3Flame Graph & Service Dependency Map

Flame Graph (type="flame") folds repeated call paths — such as the 5 vector-shard probes and 3 Postgres chunk fetches in our AI Hybrid RAG trace — into cumulative hotspot boxes. Service Map (type="service") renders a directed topology of all 9 microservices and their inferred external peers (Qdrant, Elasticsearch, Redis, Postgres, Kafka) with live latency and error rates.

Try synchronized exploration: Double-click any Flame box (or press F) to zoom that call path to full width (Escape steps out). Switch to Service Map to pan/zoom the 2D DAG and click a service node or edge — selection stays synchronized across tabs.

6Service Lanes & Concurrency

<trace-view type="lanes"> draws one swimlane per service on a shared time axis, so you can see who was busy when and how much ran in parallel. Each lane is split into levels: concurrent spans are packed into as few rows as possible, and a child always sits below its same-service parent. Services' external dependencies appear as ghost peer lanes (italic name, hatched or outlined bars): calls seen from the caller to an uninstrumented database, cache, broker, or host. When thousands of spans fall inside a few pixels, they collapse into merged hatched bars whose tooltip shows the count; zoom in to split them again.

A lane taller than max-rows is capped with a +N rows overflow row (click it to show every level). A collapsed lane becomes a one-row in-flight concurrency area chart with error ticks; with a filter active it counts only matching requests. The gutter reports each lane's spans · busy % · peak concurrency · errors, and hovering an empty gap inside a lane shows its idle time. Selecting a span fades everything outside its request's causal tree.

Try it on the worker pool: 40 image tasks run on an 8-slot image-worker pool, so that lane stays pinned at 8 concurrent spans (saturation), preceded by a ~120 ms idle gap while job-scheduler waits on an uninstrumented feature-flag call. Hover the empty space before the first task, collapse image-worker to see its concurrency curve, then switch on Errors Only to count only the 3 failing tasks.

Lanes vs. Waterfall vs. Flame Graph

ViewBest for
LanesConcurrency and saturation per service: worker pools, fan-out, idle gaps, retry storms, and who was busy at a given moment. Handles tens of thousands of spans through merging.
WaterfallOne request's causal tree in call order: exact parent/child nesting, per-span timing, and log events.
Flame GraphWhere the cumulative time went: identical call paths folded into hotspot boxes, with no time axis.

8Extending with registerView()

Register custom views implementing TraceView via registerView({ id, label, capabilities, create }) and declare them alongside built-in views as <trace-view type="your-id">. Below is a live Slowest Spans leaderboard over the 43-span AI Hybrid RAG trace sharing filter and selection state with Waterfall and Flame Graph.

JavaScript — Registering a Custom Synchronized View 
import { registerView, formatDuration, spanKindName } from 'log2trace-ui';

// Register before <trace-visualizer> upgrades (or set viz.view = 'hot-spans'
// after re-inserting its <trace-view> carrier if the element was already parsed).
registerView({
  id: 'hot-spans',
  label: 'Slowest Spans',
  capabilities: { legend: false },
  create() {
    let root = null;
    let ctx = null;

    function render() {
      if (!root || !ctx) return;
      const { data, selection, matched } = ctx.store.state;
      const rows = [...data.index.ordered]
        .filter((s) => matched === null || matched.has(s.spanId))
        .sort((a, b) => b.durationMs - a.durationMs);
      // Render rows and write selection back via:
      // ctx.store.setSelection([span.spanId], { origin: ctx.origin, primary: span.spanId });
    }

    return {
      mount(surface, viewCtx) {
        ctx = viewCtx;
        root = document.createElement('div');
        surface.appendChild(root);
        render();
      },
      update() { render(); },
      optionsChanged() {},
      themeChanged() { render(); },
      commands: () => [],
      getState: () => null,
      setState() {},
      unmount() { root?.remove(); root = null; ctx = null; },
    };
  },
});
